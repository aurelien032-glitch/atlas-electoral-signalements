# Signaler une vulnérabilité

Cette page concerne la **sécurité** de [atlas-electoral.fr](https://atlas-electoral.fr) et des fichiers de données qu'il
publie (`atlas-electoral.fr/data/v1`). Le code du site n'est pas publié.

## Comment signaler

Utilisez le signalement privé de GitHub : onglet **Security** de ce dépôt, puis **Report a vulnerability**
([lien direct](https://github.com/aurelien032-glitch/atlas-electoral-signalements/security/advisories/new)).
**N'ouvrez pas de ticket public** pour une vulnérabilité : il serait lisible par tous avant d'être corrigée.

Indiquez l'adresse concernée, ce que vous avez fait, ce que vous avez constaté et, si possible, comment le reproduire.

## À quoi vous attendre

Le site est tenu par un particulier. Je réponds en général dans les jours qui suivent, sans engagement de délai de
correction. Il n'y a pas de prime. Merci de ne pas accéder aux données d'autrui, de ne pas perturber le service
(pas de déni de service) et de me laisser le temps de corriger avant toute publication.

## Ce qui ne relève pas de cette page

- **Une erreur dans un chiffre, une carte ou un classement** : utilisez le formulaire « Signaler une erreur » du
  site, ou [ouvrez un ticket](https://github.com/aurelien032-glitch/atlas-electoral-signalements/issues/new?template=erreur.yml).
- **Les services tiers** que le site interroge (IGN, geo.api.gouv.fr, data.gouv.fr, Cloudflare) : voir leurs
  propres pages de signalement.

Cette politique est aussi publiée à l'adresse
[`/.well-known/security.txt`](https://atlas-electoral.fr/.well-known/security.txt) du site.
